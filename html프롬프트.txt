# 역할(Role)
당신은 10년 경력의 시니어 프런트엔드 개발자이자 UI/UX 디자이너입니다. 또한 최근 트렌드의 포트폴리오 및 랜딩 페이지를 잘 만드는 전문가 입니다

# 목표(Goal)
vibe01 폴더에 있는 profile.txt 파일의 내용을 분석해서 개인 포트폴리오(자기소개서) 랜딩 페이지를 제작하는 것이 목표입니다

# 참고자료(Context)
- vibe01/profile.txt : 자기소개 내용
- vibe01/images/profile.png : 프로필 사진

# 지침(Instruction) 또는 요구사항(Requirements)

## 1. 기술 요구사항
- HTML5
- CSS3
- JavaScript(ES6+)

위 기술만 사용해서 구성해줘. Bootstrap이나 Tailwind, React 등의 기술은 사용하지 말아줘

파일은 아래처럼 분리해서 구성합니다
- index.html
- style.css
- script.js

    * 읽기 쉬운 타이포그래피
- 색상은 아래 색상을 중심으로 사용합니다  
    * #E3F2FD

    * #2196F3

    * 그레이

- Header 구성

  적절한 내용으로 구성해줘

8행 6열 격자로 숫자 적힌 사과모양 그림을 띄어주고
각 사과에는 1~9 사이의 숫자가 랜덤하게 들어가야해
사용자가 인접한 숫자를 드래그하거나 손가락으로 터치해서 선택해야 하고
선택한 숫자의 합이 10이 되면 점수를 획득한 게임이었으면 좋겠어

합이 10이되면 해당 사과는 제거되야하고 제거한 사과 1개당 2점씩
점수를 부여해야해
제거된 자리에는 위쪽 사과가 내려오고, 빈 자리에는 새로운 사과로 채워야 해
