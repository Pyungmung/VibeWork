# 사과 숫자 퍼즐 게임 앱 기획서 프롬프트

## 1. 프로젝트 요청

HTML, CSS, JavaScript만 사용해 누구나 파일을 열어 바로 실행할 수 있는 간단한 웹게임을 만들어줘.
게임 이름은 **사과 숫자 퍼즐**로 한다. 별도의 프레임워크, 빌드 도구, 서버, 외부 라이브러리 없이 구현하고, `index.html`, `style.css`, `script.js`로 파일을 분리한다. 이미지 파일이 없어도 실행할 수 있도록 사과 모양은 CSS 또는 인라인 SVG로 구현한다.

## 2. 핵심 게임 규칙

- 게임 보드는 **8행 6열**, 총 48칸의 격자로 표시한다.
- 각 칸에는 사과 모양의 타일 하나를 표시한다.
- 모든 사과에는 **1부터 9 사이의 숫자**를 랜덤으로 넣는다.
- 사용자는 서로 인접한 사과를 마우스로 드래그하거나 손가락으로 터치해 연속해서 선택한다.
- 인접은 상하좌우를 기본으로 하며, 대각선은 선택할 수 없게 한다.
- 드래그 중에는 현재 선택된 사과를 시각적으로 표시하고, 선택된 숫자의 합계를 즉시 보여준다.
- 선택한 숫자의 합이 **정확히 10**이 되면 성공 처리한다.
- 합이 10이 된 선택 경로의 사과를 모두 제거한다.
- 제거된 사과 **1개당 2점**을 부여한다. 예를 들어 사과 4개를 제거하면 8점이다.
- 선택한 숫자의 합이 10을 초과하면 해당 선택을 즉시 취소하고 원래 상태로 되돌린다.
- 드래그를 끝냈을 때 합이 10이 아니면 선택을 취소하며 점수는 올리지 않는다.
- 같은 사과를 한 번의 선택 경로에서 중복 선택할 수 없게 한다.
- 한 번 선택한 사과는 경로를 되돌아가 선택 해제할 수 있도록 구현해도 좋지만, 현재 합이 10을 초과하는 순간에는 선택을 취소한다.

## 3. 사과 제거 및 보드 채우기

합이 10이 되어 사과를 제거하면 다음 순서로 보드를 갱신한다.

1. 선택된 사과 타일을 제거한다.
2. 각 열에서 위쪽에 있는 사과가 아래로 내려오도록 중력 효과를 적용한다.
3. 각 열의 위쪽에 생긴 빈 칸을 1~9 사이의 새 숫자를 가진 사과로 채운다.
4. 갱신이 끝난 뒤에도 8행 6열, 총 48개의 사과가 항상 유지되도록 한다.
5. 사과가 내려오고 새로 생성되는 과정을 짧은 CSS 애니메이션으로 표현한다.
6. 보드 갱신 중에는 중복 입력이 발생하지 않도록 잠시 입력을 제한한다.

## 4. 화면 구성

첫 화면에서 별도의 설명 페이지를 거치지 않고 바로 게임을 시작할 수 있게 한다. 화면에는 다음 요소를 포함한다.

- 게임 제목: `사과 숫자 퍼즐`
- 현재 점수: `점수: 0`
- 선택 중인 숫자의 합: `합계: 0`
- 8행 6열의 게임 보드
- `다시 시작` 버튼
- 짧은 규칙 안내: “인접한 사과를 연결해 합이 10이 되면 제거하세요.”
- 게임 영역은 데스크톱과 모바일 화면에서 모두 보이도록 반응형으로 구성한다.
- 모바일에서는 한 손으로 조작하기 쉽도록 보드를 화면 중앙에 배치하고, 타일 간격과 터치 영역을 충분히 확보한다.
- 색상은 사과의 빨강과 잎의 초록을 중심으로 하되, 배경과 글자 대비를 충분히 확보한다.
- 선택된 사과는 테두리, 밝기, 크기 변화 등으로 명확히 구분한다.

## 5. 조작 및 입력 처리

- 마우스 입력과 터치 입력을 모두 지원한다.
- 가능하면 `Pointer Events`를 사용해 마우스와 터치 로직을 하나로 관리한다.
- 포인터가 첫 사과 위에서 시작했을 때만 선택을 시작한다.
- 포인터가 인접한 다른 사과로 이동하면 해당 사과를 선택 경로에 추가한다.
- 인접하지 않은 칸으로 이동하거나 이미 선택한 사과로 이동한 경우에는 경로에 추가하지 않는다.
- 포인터를 놓으면 선택을 종료하고 합계를 판정한다.
- 브라우저의 기본 드래그, 텍스트 선택, 모바일 페이지 스크롤이 게임 조작을 방해하지 않도록 게임 보드에 적절한 `touch-action`과 선택 방지 스타일을 적용한다.
- 키보드만 사용하는 사용자를 위해 가능하다면 포커스 표시와 기본적인 접근성 속성도 제공한다.

## 6. 게임 상태와 판정

JavaScript에서 다음 상태를 명확하게 관리한다.

- 8행 6열 숫자 배열
- 현재 점수
- 현재 선택된 타일 목록
- 현재 선택 합계
- 포인터 입력이 진행 중인지 여부
- 사과 제거 및 낙하 애니메이션 중인지 여부

다음 상황을 정확히 처리한다.

- 합계가 10: 선택 타일 제거, 타일 수 × 2점만큼 점수 증가, 보드 재배치
- 합계가 10 초과: 선택 취소 및 합계 초기화
- 포인터를 놓았을 때 합계가 10 미만: 선택 취소 및 합계 초기화
- 보드가 갱신된 뒤에는 새 선택을 시작할 수 있음
- 숫자 배열과 화면 타일의 행·열 위치가 항상 일치해야 함

## 7. 게임 종료 조건과 다시 시작

- 기본 버전에서는 별도의 제한 시간 없이 계속 플레이할 수 있게 한다.
- 더 이상 합이 10이 되는 인접 경로를 찾을 수 없는 경우를 확인할 수 있다면 “게임 종료” 화면과 최종 점수를 표시한다.
- 게임 종료 판정 구현이 복잡할 경우에는 먼저 무제한 플레이 버전을 완성하고, 종료 판정은 확장 기능으로 분리한다.
- `다시 시작` 버튼을 누르면 점수를 0으로 초기화하고, 새로운 랜덤 숫자로 48개 사과를 채운다.
- 다시 시작 중에는 진행 중인 선택과 애니메이션을 정리해 이전 게임 상태가 남지 않도록 한다.

## 8. 시각 디자인 및 애니메이션

- 사과 타일은 둥근 사과 몸통, 잎, 숫자로 구성해 한눈에 사과로 인식되게 한다.
- 숫자는 충분히 크고 굵게 표시해 모바일에서도 읽기 쉽도록 한다.
- 선택 중인 타일은 강조 색상이나 확대 효과를 사용한다.
- 제거 시 사라지는 효과, 위쪽 사과가 내려오는 효과, 새 사과가 나타나는 효과를 짧고 자연스럽게 적용한다.
- 애니메이션이 게임 판정을 방해하지 않도록 상태 변경과 화면 렌더링 순서를 일관되게 유지한다.
- `prefers-reduced-motion`을 지원해 모션 감소를 선호하는 사용자에게는 애니메이션을 줄인다.

## 9. 접근성 및 품질 기준

- 버튼과 주요 게임 영역에 의미 있는 `aria-label`을 제공한다.
- 색상만으로 선택 상태를 전달하지 말고 테두리나 크기 변화도 함께 사용한다.
- 텍스트와 배경의 대비를 충분히 확보한다.
- 콘솔 오류가 없어야 하며, 새로고침 후에도 바로 게임이 실행되어야 한다.
- 데스크톱 마우스 드래그, 모바일 터치 드래그, 합계 10 성공, 합계 10 초과 취소, 사과 제거 점수, 열별 낙하, 새 사과 생성, 다시 시작을 직접 테스트한다.

## 10. 산출물

다음 파일을 `vibe02` 폴더에 작성한다.

- `index.html`: 게임 화면의 구조와 접근성 속성
- `style.css`: 반응형 레이아웃, 사과 디자인, 상태 스타일, 애니메이션
- `script.js`: 랜덤 보드 생성, 포인터 입력, 인접 판정, 합계 판정, 점수 계산, 사과 제거와 열별 낙하, 재시작

완성 후 `index.html`을 브라우저에서 직접 열어도 동작하는지 확인하고, 사용자가 별도 설치 없이 게임을 실행할 수 있도록 한다.
